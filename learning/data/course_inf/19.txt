=== theory: Как устроена игра
<p>Задания 19, 20 и 21 — три вопроса к одному условию. Два игрока, Петя и Ваня, по очереди делают ходы; первым ходит Петя. Перед ними куча камней (или две кучи). За ход можно, например, добавить в кучу один камень, добавить четыре или удвоить количество. Игра заканчивается, когда в куче становится не меньше заданного числа камней; выигрывает тот, кто сделал последний ход. В начале в куче S камней, и нужно найти значения S с особыми свойствами.</p>
<h3>Выигрышные и проигрышные позиции</h3>
<ul>
<li>Позиция <strong>выигрышная</strong> для того, кто ходит, если у него есть ход в проигрышную для соперника позицию.</li>
<li>Позиция <strong>проигрышная</strong>, если любой ход ведёт в выигрышную для соперника позицию.</li>
<li>Игроки играют наилучшим образом: выигрывающий стремится выиграть как можно быстрее, проигрывающий — затянуть игру.</li>
</ul>
<p>Удобно считать <em>число ходов до конца игры</em> (ходы обоих игроков подряд). Обозначим p(S): положительное значение — тот, кто ходит, выигрывает, и игра длится p(S) ходов; отрицательное — ходящий проигрывает за |p(S)| ходов; 0 — игра уже окончена.</p>
<h3>Что значат вопросы</h3>
<table>
<thead><tr><th>Формулировка</th><th>p(S)</th></tr></thead>
<tbody>
<tr><td>Петя выигрывает первым ходом</td><td>1</td></tr>
<tr><td>Ваня выигрывает первым ходом при любом ходе Пети</td><td>−2</td></tr>
<tr><td>Петя выигрывает вторым ходом (но не может первым)</td><td>3</td></tr>
<tr><td>Ваня выигрывает первым или вторым ходом при любой игре Пети, но не может гарантированно выиграть первым</td><td>−4</td></tr>
</tbody>
</table>
<p>Вариант «Ваня выиграл первым ходом после <em>неудачного</em> хода Пети» означает: у Пети есть ход в позицию, где p = 1 для Вани, а сам Петя первым ходом выиграть не может.</p>

=== theory: Программа для любой игры
<p>Функция ниже считает p(S) рекурсивно с запоминанием. Меняются только ходы и условие окончания игры.</p>
--- code
from functools import lru_cache

GOAL = 50                                # игра заканчивается, когда камней не меньше 50

def moves(s):
    return s + 1, s + 4, s * 2           # возможные ходы из позиции s

@lru_cache(None)
def p(s):
    if s >= GOAL:
        return 0                         # игра окончена: ходивший перед нами выиграл
    after = [p(m) for m in moves(s)]
    losing = [x for x in after if x <= 0]           # куда можно сходить, чтобы соперник проиграл
    if losing:
        return 1 - max(losing)                       # выигрываем как можно быстрее
    return -(1 + max(after))                         # проигрываем как можно дольше

S = range(1, GOAL)
print('19:', [s for s in S if p(s) == -2])           # [24]
print('20:', [s for s in S if p(s) == 3])            # [12, 20, 23]
print('21:', [s for s in S if p(s) == -4])           # [19, 22]
--- end
<p>Для этой игры (ходы +1, +4, ×2, конец при 50 камнях): ответ на вопрос 19 — <strong>24</strong>; на 20 (два наименьших значения) — <strong>12 20</strong>; на 21 (наименьшее значение) — <strong>19</strong>.</p>
<p>Проверим 19 вручную: из 24 Петя может получить 25, 28 или 48 камней — до 50 не дотягивает. Но из 25 Ваня удваивает до 50, из 28 удваивает до 56, из 48 добавляет четыре и получает 52. Ваня выигрывает при любом ходе Пети.</p>
<h3>Две кучи</h3>
<p>Если куч две, позиция — пара (a, b), ход применяется к одной из куч, а условие окончания — к сумме. Функция та же, меняются только <code>moves</code> и проверка конца:</p>
--- code
def moves(pos):
    a, b = pos
    return (a + 1, b), (a * 2, b), (a, b + 1), (a, b * 2)

def finished(pos):
    return sum(pos) >= GOAL
--- end
<h3>Частые ошибки</h3>
<ul>
<li>Путать «первым ходом» и «за два хода»: ходы считают по игроку, а p(S) — по ходам обоих.</li>
<li>Забыть «наилучшую игру»: выигрывающий выбирает самый быстрый выигрыш, проигрывающий — самый долгий проигрыш.</li>
<li>Не проверить, что в 21 Ваня <em>не может</em> гарантированно выиграть первым ходом: такие S дают −2, а не −4.</li>
</ul>

=== quiz: Проверь себя: проигрышная позиция
? Когда позиция проигрышная для того, кто сейчас ходит?
+ Когда любой его ход ведёт в выигрышную для соперника позицию
- Когда у него есть хотя бы один плохой ход
- Когда в куче мало камней
- Когда соперник ходил первым
>> Проигрышная позиция — та, из которой нет хода в проигрышную позицию соперника. Если есть хотя бы один такой ход, позиция выигрышная — даже если остальные ходы плохие.

=== answer: Мини-задача
<p>Игра: в куче S камней (1 ≤ S ≤ 39). За ход можно добавить в кучу два камня или утроить их количество. Игра заканчивается, когда в куче становится не меньше 40 камней. Первым ходит Петя.</p>
<p>Найдите наименьшее S, при котором Петя не может выиграть первым ходом, но выигрывает своим вторым ходом при любой игре Вани.</p>
= 4
>> Из 4 Петя утраивает до 12. Ваня может сделать 14 или 36: из 14 Петя утраивает до 42, из 36 — до 108. Первым ходом из 4 Петя выиграть не может (6 и 12 меньше 40). Программа с ходами s + 2, s * 3 и GOAL = 40 даёт значения 4, 10, 11; наименьшее — 4.

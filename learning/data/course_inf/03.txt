=== theory: Как устроена база данных из нескольких таблиц
<p>К заданию прилагается файл электронной таблицы с несколькими листами — это небольшая <strong>реляционная база данных</strong>. Обычно есть справочники (товары, магазины, сотрудники) и журнал операций (движение товаров, продажи). Нужно отобрать строки журнала по условиям из разных листов и посчитать итог: количество, сумму, выручку.</p>
<h3>Ключи и связи</h3>
<ul>
<li>У каждой строки справочника есть <strong>ключ</strong> — уникальный идентификатор: артикул, ID магазина.</li>
<li>Журнал хранит не название товара, а его ключ. Чтобы узнать отдел или название, ищут строку справочника с тем же ключом. Это и есть связь таблиц.</li>
<li>Условие задачи почти всегда смешивает листы: «товары молочного отдела» — из справочника товаров, «магазины Северного района» — из справочника магазинов, «поступление» и количество — из журнала.</li>
</ul>
<h3>Порядок решения в электронной таблице</h3>
<ol>
<li>На листе журнала добавьте столбцы с нужными свойствами из справочников: функцией <code>ВПР</code> (<code>VLOOKUP</code>) или <code>ПРОСМОТРX</code> подтяните отдел по артикулу и район по ID магазина.</li>
<li>Включите фильтр и отберите строки по всем условиям: отдел, район, тип операции, период.</li>
<li>Посчитайте итог по видимым строкам (строка состояния показывает сумму выделенного) или формулой <code>СУММЕСЛИМН</code>.</li>
<li>Если спрашивают выручку или вес, сначала добавьте столбец с произведением (количество × цена), потом суммируйте.</li>
</ol>
<h3>То же на Python</h3>
<p>Библиотека pandas читает все листы файла и соединяет таблицы по ключам одной командой <code>merge</code>. Названия листов и столбцов в каждом файле свои — сначала посмотрите на них.</p>
--- code
import pandas as pd

book = pd.read_excel('3.xlsx', sheet_name=None)   # словарь: имя листа -> таблица
for name, sheet in book.items():
    print(name, list(sheet.columns))                # сначала узнаём названия

moves = book['Движение товаров']
data = moves.merge(book['Товар'], on='Артикул').merge(book['Магазин'], on='ID магазина')
part = data[(data['Отдел'] == 'Молочный')
            & (data['Район'] == 'Северный')
            & (data['Тип операции'] == 'Поступление')]
print(part['Количество упаковок, шт.'].sum())
--- end
<h3>Частые ошибки</h3>
<ul>
<li>Не учесть одно из условий — например, тип операции (поступление и продажа в одном журнале).</li>
<li>Перепутать единицы: упаковки и килограммы, рубли и тысячи рублей. Читайте, в чём просят ответ.</li>
<li>Проверить итог «на глаз» по одному листу, не связав таблицы.</li>
</ul>

=== quiz: Проверь себя: зачем ключ
? Почему в журнале «Движение товаров» записан артикул, а не название и отдел товара?
+ Чтобы связать строку журнала со справочником товаров по ключу
- Чтобы в журнале было меньше строк
- Так требует программа электронных таблиц
- Чтобы скрыть название товара от продавцов
>> Артикул — ключ справочника. По нему из журнала находится вся информация о товаре: название, отдел, цена. Данные о товаре хранятся в одном месте и не повторяются в каждой операции.

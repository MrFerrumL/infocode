summary: Сопоставить схему дорог и таблицу расстояний, где пункты пронумерованы по-разному.
lesson: Граф и таблица: сопоставляем вершины
minutes: 35

=== theory: Как устроено задание
<p>Даны два описания одной и той же сети дорог: <strong>граф</strong> (рисунок, вершины обозначены буквами) и <strong>таблица</strong> (весовая матрица, пункты обозначены номерами). Рисовали их независимо, поэтому буква A не обязательно соответствует пункту 1. Нужно понять, какой номер у какой буквы, и найти в таблице длину дороги (или сумму длин нескольких дорог).</p>
<h3>Ключевая идея — степень вершины</h3>
<p><strong>Степень</strong> вершины — число дорог, которые из неё выходят. На графе это число линий у вершины, в таблице — число заполненных клеток в строке пункта. Степень не зависит от того, как назвали вершину, поэтому по ней вершины и сопоставляют.</p>
<ol>
<li>Выпишите степени всех вершин графа.</li>
<li>Выпишите степени всех пунктов таблицы.</li>
<li>Вершина с уникальной степенью однозначно находит свой пункт.</li>
<li>Если степени совпадают, смотрите на соседей: с вершинами каких степеней она соединена.</li>
<li>Когда нужные вершины найдены, берите длину дороги <strong>из таблицы</strong> — на рисунке длин нет.</li>
</ol>
<h3>Пример</h3>
<p>Граф: дороги A–B, A–C, A–D, B–C, D–E. Таблица:</p>
<table>
<thead><tr><th></th><th>П1</th><th>П2</th><th>П3</th><th>П4</th><th>П5</th></tr></thead>
<tbody>
<tr><th>П1</th><td></td><td></td><td>4</td><td></td><td>6</td></tr>
<tr><th>П2</th><td></td><td></td><td></td><td>3</td><td></td></tr>
<tr><th>П3</th><td>4</td><td></td><td></td><td>9</td><td>7</td></tr>
<tr><th>П4</th><td></td><td>3</td><td>9</td><td></td><td></td></tr>
<tr><th>П5</th><td>6</td><td></td><td>7</td><td></td><td></td></tr>
</tbody>
</table>
<p>Найдём длину дороги A–D. Степени графа: A — 3, B — 2, C — 2, D — 2, E — 1. Степени таблицы: П1 — 2, П2 — 1, П3 — 3, П4 — 2, П5 — 2.</p>
<ul>
<li>Степень 3 только у A и у П3, значит A = П3.</li>
<li>Степень 1 только у E и у П2, значит E = П2.</li>
<li>D — единственный сосед E, а у П2 единственный сосед — П4. Значит D = П4.</li>
</ul>
<p>Дорога A–D — это клетка П3–П4: <strong>ответ 9</strong>. Вершины B и C при этом различать не нужно — они симметричны, а про них не спрашивают.</p>
<h3>Частые ошибки</h3>
<ul>
<li>Считать заполненные клетки по столбцу и по строке вместе — таблица симметрична, достаточно строки.</li>
<li>Сопоставлять вершины по положению на рисунке или по алфавиту.</li>
<li>Отвечать «длиной» с рисунка: ответ всегда берётся из таблицы.</li>
</ul>
<h3>Проверка программой</h3>
<p>Руками задание решается за пару минут, но для самопроверки можно перебрать все соответствия букв и номеров. Соответствие подходит, если дороги графа и таблицы совпадают.</p>
--- code
from itertools import permutations

graph = {'AB', 'AC', 'AD', 'BC', 'DE'}            # дороги на рисунке
table = {(1, 3): 4, (1, 5): 6, (2, 4): 3, (3, 4): 9, (3, 5): 7}
roads = {frozenset(pair) for pair in table}

for numbers in permutations(range(1, 6)):
    name = dict(zip('ABCDE', numbers))            # буква -> номер пункта
    if {frozenset((name[a], name[b])) for a, b in graph} == roads:
        a, d = sorted((name['A'], name['D']))
        print(name, 'A–D =', table[(a, d)])
--- end
<p>Программа напечатает два соответствия (B и C можно поменять местами), и в обоих A–D = 9.</p>

=== quiz: Проверь себя: что видно в таблице
? В строке пункта П4 таблицы заполнены три клетки. Что это означает?
+ Из пункта П4 выходят три дороги
- Длина дороги из П4 равна 3
- П4 соответствует третьей букве на рисунке
- П4 соединён со всеми остальными пунктами
>> Заполненная клетка — это дорога. Три клетки в строке — три дороги, то есть степень пункта равна 3. Длины записаны в самих клетках.

=== answer: Мини-задача
<p>Граф: дороги A–B, A–C, B–C, C–D.</p>
<p>Таблица (в скобках — длина дороги): П1–П2 (5), П1–П3 (8), П2–П3 (2), П2–П4 (6).</p>
<p>Найдите длину дороги C–D.</p>
= 6
>> Степени графа: A — 2, B — 2, C — 3, D — 1. Степени таблицы: П1 — 2, П2 — 3, П3 — 2, П4 — 1. Значит C = П2, D = П4, а дорога П2–П4 имеет длину 6.

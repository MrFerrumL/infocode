title: № 15 · Логические выражения с параметром
summary: Подобрать параметр A, при котором логическое выражение истинно при любых значениях переменной.
lesson: Тождественная истинность: отрезки, делимость, поразрядные операции
minutes: 40

=== theory: Что значит «тождественно истинно»
<p>Дано логическое выражение с переменной x (иногда x и y) и параметром A. Нужно найти наименьшее или наибольшее A, при котором выражение истинно <strong>при любом</strong> допустимом x. Встречаются три вида условий:</p>
<ul>
<li><strong>Отрезки</strong>: x ∈ P, x ∈ Q, x ∈ A — точка x лежит на отрезке числовой прямой.</li>
<li><strong>Делимость</strong>: ДЕЛ(x, n) — x делится на n без остатка.</li>
<li><strong>Поразрядная конъюнкция</strong>: x &amp; n — побитовое И чисел; условие вида x &amp; n ≠ 0 означает «у x есть хотя бы один общий единичный бит с n».</li>
</ul>
<h3>Главный приём — искать, когда выражение ложно</h3>
<p>Импликация a → b ложна только при a = 1, b = 0. Поэтому удобно выписать условие, при котором всё выражение ложно, и подобрать A так, чтобы такого x не существовало.</p>
<h3>Пример с поразрядной конъюнкцией</h3>
<p>Найдём наименьшее натуральное A, при котором выражение (x &amp; A = 0) → ((x &amp; 13 ≠ 0) → (x &amp; 22 ≠ 0)) истинно при любом целом неотрицательном x.</p>
<ol>
<li>Выражение ложно, когда x &amp; A = 0, x &amp; 13 ≠ 0 и x &amp; 22 = 0.</li>
<li>13 = 01101<sub>2</sub> (биты 8, 4, 1), 22 = 10110<sub>2</sub> (биты 16, 4, 2). Из-за x &amp; 22 = 0 бит 4 у x равен нулю, значит x &amp; 13 ≠ 0 возможно только за счёт битов 8 или 1.</li>
<li>Чтобы такого x не было, A должно «ловить» и бит 8, и бит 1: тогда x &amp; A ≠ 0. Наименьшее такое A = 8 + 1 = <strong>9</strong>.</li>
</ol>
<h3>Перебор на Python</h3>
<p>Рассуждение легко проверить перебором: для каждого A проверяем все x из достаточно большого диапазона.</p>
--- code
def f(x, a):
    return (x & a != 0) or (x & 13 == 0) or (x & 22 != 0)   # a → b записано как ¬a ∨ b

for a in range(1, 1000):
    if all(f(x, a) for x in range(1024)):
        print(a)        # 9
        break
--- end
<p>Импликацию удобно переписывать через <code>not a or b</code> или <code>a &lt;= b</code>. В Python операция <code>&amp;</code> выполняется раньше сравнения, поэтому <code>x &amp; a != 0</code> означает именно <code>(x &amp; a) != 0</code>. В C++ порядок другой (там <code>!=</code> выполняется раньше <code>&amp;</code>) — если пишете на нём, обязательно ставьте скобки. Лишние скобки не вредят и в Python: так запись читается легче.</p>
<h3>Делимость и отрезки</h3>
<ul>
<li>ДЕЛ(x, n) в Python — <code>x % n == 0</code>. Перебирайте x от 1 до нескольких тысяч.</li>
<li>Для отрезков перебирайте x с шагом 0,5 или 0,25 — так видны концы отрезков, — либо рассуждайте на числовой прямой: какую часть прямой должен закрыть отрезок A.</li>
</ul>

=== quiz: Проверь себя: когда импликация ложна
? Выражение (x ∈ P) → (x ∈ Q) ложно для точки x. Что это значит?
+ x лежит на P, но не лежит на Q
- x не лежит ни на P, ни на Q
- x лежит и на P, и на Q
- x лежит на Q, но не лежит на P
>> Импликация ложна только при истинной посылке и ложном следствии: x ∈ P истинно, x ∈ Q ложно.

=== answer: Мини-задача
<p>На числовой прямой даны отрезки P = [10, 40] и Q = [25, 60]. Найдите наименьшую возможную длину отрезка A, при котором выражение</p>
<p>(x ∈ P) → ((x ∈ Q) ∨ (x ∈ A))</p>
<p>истинно при любом x.</p>
= 15
>> Выражение ложно, когда x ∈ P, x ∉ Q и x ∉ A. Точки P, не лежащие на Q, — это [10, 25). Отрезок A должен закрыть их все, наименьший такой — [10, 25], его длина 15.

title: № 17 · Обработка последовательности из файла
summary: Найти в файле пары соседних чисел с условиями и посчитать количество и экстремальную сумму.
lesson: Пары соседних элементов и условия на всю последовательность
minutes: 35

=== theory: Как устроено задание
<p>Дан файл с целыми числами — по одному в строке. Обычно рассматривают <strong>пары</strong>: два элемента, стоящие рядом (иногда — тройки или пары с любыми индексами). Нужно найти количество пар, удовлетворяющих условиям, и, например, максимальную сумму элементов таких пар. <strong>Ответ — два числа через пробел</strong>.</p>
<h3>Условия бывают двух видов</h3>
<ul>
<li><strong>Про саму пару</strong>: хотя бы одно число делится на 13; ровно одно число трёхзначное; оба отрицательные.</li>
<li><strong>Про всю последовательность</strong>: сумма пары меньше наибольшего элемента, оканчивающегося на 5; больше среднего арифметического всех чисел. Такие величины считают <em>один раз до перебора пар</em>.</li>
</ul>
<h3>Шаблон программы</h3>
--- code
seq = [int(line) for line in open('17.txt')]

limit = max(x for x in seq if abs(x) % 10 == 5)      # считаем до перебора пар

sums = []
for a, b in zip(seq, seq[1:]):                       # все пары соседей
    if (a % 13 == 0 or b % 13 == 0) and a + b < limit:
        sums.append(a + b)
print(len(sums), max(sums))
--- end
<p><code>zip(seq, seq[1:])</code> выдаёт пары (seq[0], seq[1]), (seq[1], seq[2]), … — ровно все пары соседей. Для троек используйте <code>zip(seq, seq[1:], seq[2:])</code>.</p>
<h3>Пример на коротком списке</h3>
<p>Последовательность: 26, 39, 5, 120, 13, 85, 52, 7, 65, 400, 91, 15. Наибольший элемент, оканчивающийся на 5, — 85. Подходят пары (26, 39), (39, 5), (52, 7), (7, 65): суммы 65, 44, 59, 72. Пара (120, 13) не подходит — сумма 133 не меньше 85. Ответ: <strong>4 72</strong>.</p>
<h3>Частые ошибки</h3>
<ul>
<li>Отрицательные числа: в Python <code>-13 % 10</code> равно 7, а не 3. Поэтому последнюю цифру берут через модуль: <code>abs(x) % 10 == 3</code>. Нечётность <code>x % 2 != 0</code> проверяется правильно и для отрицательных.</li>
<li>«Трёхзначное» — это 100 ≤ |x| ≤ 999, тоже с модулем.</li>
<li>Пересчитывать «наибольший элемент…» внутри цикла по парам: долго и легко ошибиться.</li>
<li>Записать ответ в одну ячейку слитно — нужны два числа через пробел.</li>
</ul>

=== quiz: Проверь себя: сколько пар
? В файле 10 000 чисел. Сколько всего пар соседних элементов?
+ 9 999
- 10 000
- 5 000
- 49 995 000
>> Пары соседей: (1, 2), (2, 3), …, (9 999, 10 000) — на одну меньше, чем элементов. 5 000 получилось бы при разбиении на непересекающиеся пары, 49 995 000 — для пар с любыми индексами.

=== answer: Мини-задача
<p>Последовательность: 12, 45, 7, 30, 18, 64, 9, 27, 50, 6.</p>
<p>Найдите количество пар соседних элементов, в которых <strong>ровно одно</strong> число делится на 3, а большее число пары больше среднего арифметического всех чисел последовательности. Затем — максимальную сумму элементов таких пар. Запишите два числа через пробел.</p>
= 6 82
>> Среднее арифметическое 268 / 10 = 26,8. Подходят пары (45, 7), (7, 30), (18, 64), (64, 9), (27, 50), (50, 6) — их 6, суммы 52, 37, 82, 73, 77, 56. Пары (12, 45), (30, 18), (9, 27) отпадают: в них оба числа делятся на 3.

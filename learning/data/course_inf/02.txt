=== theory: Логические операции и их запись в Python
<p>В задании дана логическая функция от четырёх переменных x, y, z, w и <strong>фрагмент</strong> её таблицы истинности: несколько строк, часть клеток пустые, а над столбцами вместо имён переменных — пропуски. Нужно выяснить, какой переменной соответствует каждый столбец, и записать буквы в порядке столбцов.</p>
<h3>Операции</h3>
<table>
<thead><tr><th>Операция</th><th>Запись</th><th>Истинна, когда…</th><th>В Python (для 0 и 1)</th></tr></thead>
<tbody>
<tr><td>Отрицание</td><td>¬a</td><td>a ложно</td><td><code>not a</code></td></tr>
<tr><td>Конъюнкция (И)</td><td>a ∧ b</td><td>оба истинны</td><td><code>a and b</code></td></tr>
<tr><td>Дизъюнкция (ИЛИ)</td><td>a ∨ b</td><td>хотя бы одно истинно</td><td><code>a or b</code></td></tr>
<tr><td>Импликация</td><td>a → b</td><td>кроме случая a = 1, b = 0</td><td><code>a &lt;= b</code></td></tr>
<tr><td>Эквивалентность</td><td>a ≡ b</td><td>значения совпадают</td><td><code>a == b</code></td></tr>
</tbody>
</table>
<p>Порядок действий без скобок: ¬, затем ∧, затем ∨, затем →, затем ≡. Если сомневаетесь — ставьте скобки в коде, лишними они не бывают.</p>
<h3>Как рассуждать руками</h3>
<p>Ищите «жёсткие» места формулы. Например, если F = (¬x ∨ y) ∧ (y → z) ∧ ¬w и во всех строках F = 1, то в каждой строке w = 0, а x → y и y → z вместе означают x ≤ y ≤ z. Дальше смотрите, какой столбец может быть w (в нём не должно быть единиц) и какие значения допускают остальные строки.</p>
<p>Важное правило: <strong>строки таблицы истинности различны</strong>. Если при каком-то соответствии две строки фрагмента обязаны совпасть, это соответствие не подходит.</p>
<h3>Пример</h3>
<p>F = (¬x ∨ y) ∧ (y → z) ∧ ¬w. Фрагмент (пусто — пропуск):</p>
<table>
<thead><tr><th>?</th><th>?</th><th>?</th><th>?</th><th>F</th></tr></thead>
<tbody>
<tr><td>1</td><td>0</td><td>0</td><td></td><td>1</td></tr>
<tr><td>1</td><td>1</td><td>1</td><td></td><td>1</td></tr>
<tr><td></td><td></td><td>1</td><td>0</td><td>1</td></tr>
</tbody>
</table>
<ol>
<li>F = 1, значит w = 0 во всех строках. Единицы есть в столбцах 1, 2 и 3 — значит w — это <strong>столбец 4</strong>.</li>
<li>Нужно x ≤ y ≤ z. В первой строке остальные значения 1, 0, 0 — так бывает только при x = 0, y = 0, z = 1. Единица стоит в столбце 1, значит <strong>z — столбец 1</strong>.</li>
<li>Столбцы 2 и 3 — это x и y. Если x — столбец 3, то в третьей строке x = 1, тогда y = 1 и z = 1, и третья строка совпадёт со второй (1, 1, 1, 0). Строки различны, поэтому <strong>x — столбец 2, y — столбец 3</strong>.</li>
</ol>
<p>Ответ: <strong>zxyw</strong>.</p>
<h3>Перебор на Python</h3>
<p>Надёжный способ для экзамена: перебрать, чем заполнить пустые клетки, и все перестановки букв по столбцам. Подходящая перестановка должна давать нужное значение F во всех строках, а заполненные строки — различаться.</p>
--- code
from itertools import product, permutations

def f(x, y, z, w):
    return (not x or y) and (y <= z) and not w

table = [               # None — пустая клетка, последнее число — значение F
    [1, 0, 0, None, 1],
    [1, 1, 1, None, 1],
    [None, None, 1, 0, 1],
]
blanks = sum(v is None for row in table for v in row[:4])
answers = set()
for cells in product([0, 1], repeat=blanks):
    it = iter(cells)
    rows = [[v if v is not None else next(it) for v in row[:4]] + row[4:] for row in table]
    if len({tuple(r[:4]) for r in rows}) < len(rows):
        continue                                   # строки таблицы истинности различны
    for order in permutations('xyzw'):
        if all(f(**dict(zip(order, r[:4]))) == r[4] for r in rows):
            answers.add(''.join(order))
print(answers)
--- end
<p>Программа печатает <code>{'zxyw'}</code>. Если в множестве оказалось несколько вариантов — проверьте, правильно ли переписана формула и таблица.</p>

=== quiz: Проверь себя: импликация в коде
? Какая запись в Python соответствует импликации x → y для значений 0 и 1?
+ x <= y
- x >= y
- x and not y
- not x and y
>> Импликация ложна только при x = 1, y = 0. Ровно в этом случае ложно и x <= y, во всех остальных — истинно.

=== answer: Мини-задача
<p>F = (x ∧ ¬y) ∨ (y ≡ z) ∨ w. Дан фрагмент таблицы истинности, во всех строках F = 0 (пусто — пропуск):</p>
<table>
<thead><tr><th>?</th><th>?</th><th>?</th><th>?</th><th>F</th></tr></thead>
<tbody>
<tr><td></td><td>0</td><td>0</td><td>0</td><td>0</td></tr>
<tr><td>1</td><td></td><td>0</td><td></td><td>0</td></tr>
<tr><td></td><td>1</td><td>0</td><td>0</td><td>0</td></tr>
</tbody>
</table>
<p>Какой переменной соответствует каждый столбец? Запишите буквы в порядке столбцов.</p>
= yzwx
>> F = 0 означает сразу три вещи: w = 0, y ≠ z и x → y. В столбцах 1 и 2 есть единицы, поэтому w — столбец 3 или 4. В первой строке единица может стоять только в пустой клетке столбца 1, а одна из переменных y, z обязана быть единицей — значит столбец 1 — это y или z. Оставшиеся варианты удобно проверить программой из теории: подходит единственное соответствие yzwx (y — столбец 1, z — столбец 2, w — столбец 3, x — столбец 4).

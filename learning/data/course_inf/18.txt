=== theory: Идея: лучший путь до каждой клетки
<p>Робот стоит в левой верхней клетке квадрата и ходит только <strong>вправо</strong> или <strong>вниз</strong>, собирая монеты (числа в клетках). Нужно найти наибольшую и наименьшую сумму, с которой он может прийти в правую нижнюю клетку. Иногда на поле есть стены, через которые ходить нельзя. Ответ — два числа через пробел.</p>
<p>Путей очень много, перебирать их нельзя. Но в каждую клетку робот приходит либо сверху, либо слева. Значит, лучшая сумма в клетке = число в клетке + лучшая из сумм в клетке сверху и в клетке слева. Заполняя таблицу сумм от левого верхнего угла, мы получим ответ в правом нижнем.</p>
<h3>В электронной таблице</h3>
<ol>
<li>Скопируйте поле на новый лист — там будут суммы.</li>
<li>В первой клетке — само число. В первой строке — сумма с клеткой слева, в первом столбце — с клеткой сверху.</li>
<li>В остальных клетках: <code>=МАКС(сверху; слева) + число</code>, протяните на всё поле. Для минимума — то же с <code>МИН</code> на отдельном листе.</li>
<li>Если есть стена, в клетке за ней формулу правят вручную: берут только тот сосед, откуда можно прийти.</li>
</ol>
<h3>Пример</h3>
<table>
<tbody>
<tr><td>3</td><td>1</td><td>5</td><td>2</td></tr>
<tr><td>4</td><td>8</td><td>1</td><td>6</td></tr>
<tr><td>2</td><td>7</td><td>3</td><td>1</td></tr>
<tr><td>9</td><td>1</td><td>4</td><td>5</td></tr>
</tbody>
</table>
<p>Наибольшая сумма — <strong>34</strong>, наименьшая — <strong>19</strong>. Проверьте программой:</p>
--- code
grid = [[3, 1, 5, 2],
        [4, 8, 1, 6],
        [2, 7, 3, 1],
        [9, 1, 4, 5]]

def best(grid, choose):
    n, m = len(grid), len(grid[0])
    total = [[0] * m for _ in range(n)]
    for i in range(n):
        for j in range(m):
            came = []
            if i > 0:
                came.append(total[i - 1][j])    # пришли сверху
            if j > 0:
                came.append(total[i][j - 1])    # пришли слева
            total[i][j] = grid[i][j] + (choose(came) if came else 0)
    return total[-1][-1]

print(best(grid, max), best(grid, min))           # 34 19
--- end
<p>Чтобы учесть стены, перед добавлением соседа проверяйте, нет ли стены между ним и текущей клеткой.</p>
<h3>Частые ошибки</h3>
<ul>
<li>Жадный выбор «иду туда, где больше» — он не даёт лучшего пути. Нужно именно заполнение таблицы сумм.</li>
<li>Протянуть формулу через стену.</li>
<li>Перепутать порядок: в ответе обычно сначала максимум, потом минимум.</li>
</ul>

=== quiz: Проверь себя: формула для клетки
? Робот ходит вправо и вниз. В таблице наибольших сумм клетка сверху содержит 20, клетка слева — 17, а в самой клетке монета 4. Какая наибольшая сумма в этой клетке?
+ 24
- 21
- 41
- 37
>> Робот приходит либо сверху, либо слева, поэтому берём лучший из соседей: max(20, 17) + 4 = 24. Складывать обоих соседей нельзя — робот проходит только через один из них.

=== answer: Мини-задача
<p>Робот идёт из левой верхней клетки в правую нижнюю, только вправо или вниз, и собирает числа в клетках.</p>
<table>
<tbody>
<tr><td>5</td><td>2</td><td>8</td></tr>
<tr><td>1</td><td>9</td><td>3</td></tr>
<tr><td>7</td><td>4</td><td>6</td></tr>
<tr><td>2</td><td>8</td><td>1</td></tr>
</tbody>
</table>
<p>Найдите наибольшую и наименьшую сумму. Запишите два числа через пробел: сначала наибольшую.</p>
= 29 24
>> Наибольшая: 5 → 2 → 9 → 4 → 8 → 1 = 29. Наименьшая: 5 → 1 → 7 → 2 → 8 → 1 = 24. Таблица сумм даёт те же числа без перебора путей.

=== theory: Условие Фано и двоичное дерево
<p>Сообщения кодируют двоичными кодовыми словами разной длины. Чтобы любую последовательность нулей и единиц можно было разобрать однозначно, код должен удовлетворять <strong>условию Фано</strong>: <em>ни одно кодовое слово не является началом другого</em>. Такие коды называют префиксными.</p>
<p>Обычно часть кодов уже дана, и нужно найти минимальную длину кода для какой-то буквы или минимальную суммарную длину кодов нескольких оставшихся букв.</p>
<h3>Дерево кодов</h3>
<ul>
<li>Кодовые слова — пути в двоичном дереве: шаг влево — 0, вправо — 1.</li>
<li>Занятое слово становится <strong>листом</strong>: ниже него идти нельзя (иначе оно станет началом другого слова), и выше по его пути тоже нельзя ставить слово.</li>
<li>Свободные вершины — те, путь к которым не проходит через лист и под которыми нет занятых слов. Новые буквы размещают только там.</li>
</ul>
<h3>Пример</h3>
<p>Даны коды: А — 00, Б — 010, В — 011, Г — 10. Нужно закодировать ещё три буквы Д, Е, Ж с наименьшей суммарной длиной кодов.</p>
<ol>
<li>Ветка 0: слово 00 занято; 01 разделено на 010 и 011 — тоже занято. Слева места нет.</li>
<li>Ветка 1: 10 занято, свободна только вершина <strong>11</strong>.</li>
<li>Если поставить букву прямо в 11, для двух других места не останется. Значит, вершину 11 нужно делить: 110 — одной букве, а 111 ещё раз пополам: 1110 и 1111.</li>
</ol>
<p>Суммарная длина: 3 + 4 + 4 = <strong>11</strong>.</p>
<h3>Неравенство Крафта — быстрая проверка</h3>
<p>Для префиксного кода сумма 2<sup>−длина</sup> по всем словам не больше 1. В примере уже занято 1/4 + 1/8 + 1/8 + 1/4 = 3/4, свободна четверть — ровно одна вершина длины 2, как мы и нашли деревом. Неравенство удобно, чтобы проверить ответ: если сумма превысила 1, коды не уместились.</p>
<h3>Проверка программой</h3>
--- code
def is_fano(codes):
    """Ни одно слово не является началом другого."""
    return not any(a != b and b.startswith(a) for a in codes for b in codes)

codes = ['00', '010', '011', '10', '110', '1110', '1111']
print(is_fano(codes))                          # True
print(sum(2 ** -len(c) for c in codes))        # 1.0 — дерево заполнено целиком
--- end
<h3>Частые ошибки</h3>
<ul>
<li>Ставить новую букву в вершину, которая является началом уже занятого слова (например, 01 при занятых 010 и 011).</li>
<li>Забывать, что букв нужно разместить <em>все</em>: самая короткая длина одной буквы может «съесть» место для остальных.</li>
<li>Отвечать длиной одного слова, когда спрашивают сумму длин, и наоборот.</li>
</ul>

=== quiz: Проверь себя: условие Фано
? Какой набор кодовых слов удовлетворяет условию Фано?
+ 0, 10, 110, 111
- 0, 01, 11
- 1, 10, 100
- 00, 01, 0
>> В наборе 0, 10, 110, 111 ни одно слово не является началом другого. В остальных есть нарушения: 0 — начало 01; 1 — начало 10; 0 — начало 00 и 01.

=== answer: Мини-задача
<p>Для кодирования используются слова: А — 0, Б — 100, В — 101. Нужно добавить коды для букв Г и Д так, чтобы выполнялось условие Фано, а суммарная длина кодов Г и Д была наименьшей. Чему равна эта сумма?</p>
= 6
>> Ветка 0 занята словом А. В ветке 1 вершина 10 разделена на 100 и 101 — занята. Свободна только вершина 11. Двум буквам её нужно разделить: 110 и 111, сумма длин 3 + 3 = 6.

=== theory: Редактор: замены в строке
<p>В задании дан исполнитель, который меняет строку или ленту по программе, и нужно узнать результат. Встречаются два вида исполнителей. Начнём с Редактора.</p>
<p><strong>Редактор</strong> работает со строкой символов и умеет две вещи:</p>
<ul>
<li><code>заменить(v, w)</code> — заменяет <em>первое слева</em> вхождение цепочки v на w;</li>
<li><code>нашлось(v)</code> — проверяет, есть ли в строке цепочка v.</li>
</ul>
<p>Программа — цикл <code>ПОКА</code> с условиями <code>ЕСЛИ … ТО … ИНАЧЕ</code>. Руками такой цикл выполняется десятки раз, поэтому надёжнее перенести программу на Python почти дословно: <code>нашлось(v)</code> — это <code>v in s</code>, а <code>заменить(v, w)</code> — <code>s = s.replace(v, w, 1)</code> (третий аргумент 1 — заменить только первое вхождение).</p>
<h3>Пример</h3>
<p>На вход подаётся строка из 70 единиц. Программа:</p>
<pre>ПОКА нашлось(111) ИЛИ нашлось(22)
    ЕСЛИ нашлось(111)
        ТО заменить(111, 2)
        ИНАЧЕ заменить(22, 1)
    КОНЕЦ ЕСЛИ
КОНЕЦ ПОКА</pre>
--- code
s = '1' * 70
while '111' in s or '22' in s:
    if '111' in s:
        s = s.replace('111', '2', 1)
    else:
        s = s.replace('22', '1', 1)
print(s)            # 121
--- end
<p>Если вопрос про сумму цифр или количество символов, посчитайте их по готовой строке: <code>sum(map(int, s))</code>, <code>s.count('2')</code>.</p>
<p>Частая ошибка — забыть третий аргумент <code>replace</code>: без него заменяются <em>все</em> вхождения сразу, и программа работает иначе, чем Редактор.</p>

=== theory: Машина Тьюринга: лента, головка, таблица
<p>Второй вид исполнителя — <strong>машина Тьюринга</strong> (МТ). Есть бесконечная лента из ячеек, в каждой — один символ (λ — пустая ячейка). Головка в каждый момент стоит над одной ячейкой и находится в одном из состояний q<sub>0</sub>, q<sub>1</sub>, …</p>
<p>Программа — таблица: строки — состояния, столбцы — символы. В клетке «состояние × символ под головкой» записана команда из трёх частей: <strong>какой символ записать</strong>, <strong>куда сдвинуться</strong> (L — влево, R — вправо, N — остаться, S — остановиться) и <strong>в какое состояние перейти</strong>. Сначала символ записывается, потом головка сдвигается.</p>
<h3>Как решать</h3>
<ol>
<li>Поймите, где головка стоит в начале и в каком она состоянии.</li>
<li>Пройдите несколько шагов вручную и сформулируйте, <em>что делает</em> программа: например, идёт влево и меняет каждую цифру.</li>
<li>Для длинных лент смоделируйте машину программой — это несколько строк.</li>
</ol>
<h3>Пример</h3>
<p>На ленте записано число 45 в двоичной системе (101101), слева и справа — пустые ячейки. Головка стоит в первой пустой ячейке справа от числа, состояние q<sub>0</sub>.</p>
<table>
<thead><tr><th></th><th>λ</th><th>0</th><th>1</th></tr></thead>
<tbody>
<tr><th>q<sub>0</sub></th><td>λ, L, q<sub>1</sub></td><td></td><td></td></tr>
<tr><th>q<sub>1</sub></th><td>λ, S, q<sub>1</sub></td><td>1, L, q<sub>1</sub></td><td>0, L, q<sub>1</sub></td></tr>
</tbody>
</table>
<p>В q<sub>0</sub> головка просто шагает влево на последнюю цифру. В q<sub>1</sub> она идёт влево и заменяет 0 на 1, а 1 на 0, пока не дойдёт до пустой ячейки. Каждая цифра инвертируется: 101101 → 010010 = <strong>18</strong>. Ведущий ноль в десятичной записи не нужен.</p>
--- code
def turing(number, program):
    tape = dict(enumerate(bin(number)[2:]))   # ячейка -> символ, пустые не храним
    pos, state = len(tape), 'q0'              # первая пустая ячейка справа
    while True:
        write, move, state = program[state][tape.get(pos, 'λ')]
        tape[pos] = write
        if move == 'S':
            break
        pos += {'L': -1, 'R': 1, 'N': 0}[move]
    cells = ''.join(tape[i] for i in sorted(tape)).strip('λ')
    return int(cells, 2)

invert = {'q0': {'λ': ('λ', 'L', 'q1')},
          'q1': {'0': ('1', 'L', 'q1'), '1': ('0', 'L', 'q1'), 'λ': ('λ', 'S', 'q1')}}
print(turing(45, invert))                    # 18
--- end
<p>Чтобы решить другую задачу, перепишите таблицу в словарь <code>program</code>: для каждого состояния — какой символ записать, куда сдвинуться и куда перейти.</p>

=== quiz: Проверь себя: первое вхождение
? Строка 2112, команда заменить(1, 3) выполнена один раз. Что получится?
+ 2312
- 2332
- 2113
- 3112
>> Редактор заменяет только первое слева вхождение цепочки «1»: 2112 → 2312. Вариант 2332 получился бы, если заменить все вхождения сразу.

=== answer: Мини-задача
<p>На ленте машины Тьюринга записано двоичное представление числа 47, слева и справа — пустые ячейки λ. Головка стоит в первой пустой ячейке справа от числа, в состоянии q<sub>0</sub>. Программа:</p>
<table>
<thead><tr><th></th><th>λ</th><th>0</th><th>1</th></tr></thead>
<tbody>
<tr><th>q<sub>0</sub></th><td>λ, L, q<sub>1</sub></td><td></td><td></td></tr>
<tr><th>q<sub>1</sub></th><td>1, S, q<sub>1</sub></td><td>1, S, q<sub>1</sub></td><td>0, L, q<sub>1</sub></td></tr>
</tbody>
</table>
<p>Какое число окажется на ленте после остановки? Ответ запишите в десятичной системе.</p>
= 48
>> 47 = 101111. Головка идёт справа налево: каждую 1 заменяет на 0 и идёт дальше, первую встреченную 0 заменяет на 1 и останавливается. Это прибавление единицы с переносом: 101111 → 110000 = 48.

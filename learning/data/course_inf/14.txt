=== theory: Позиционная запись и перевод
<p>В системе счисления с основанием b число записывают цифрами от 0 до b − 1; цифра на k-м месте справа (с нуля) умножается на b<sup>k</sup>. Для оснований больше 10 цифры продолжаются буквами: A = 10, B = 11, … , Z = 35.</p>
<p>Пример: 3A7<sub>11</sub> = 3 · 11<sup>2</sup> + 10 · 11 + 7 = 363 + 110 + 7 = 480.</p>
<h3>Что спрашивают</h3>
<ul>
<li><strong>Неизвестная цифра.</strong> В операндах выражения вместо одной цифры стоит x; нужно найти x, при котором значение делится на заданное число, и записать частное.</li>
<li><strong>Цифры в записи большого числа.</strong> Значение выражения вроде 9<sup>30</sup> + 3<sup>25</sup> − 7 записали в системе с основанием 3; сколько в записи двоек (нулей, значащих цифр)?</li>
</ul>
<h3>Python сделает перевод за вас</h3>
<ul>
<li><code>int('3A7', 11)</code> — перевод строки из системы с основанием 11 в число (основания от 2 до 36).</li>
<li>Обратно — делим на основание и собираем остатки; для 2, 8, 16 есть готовые <code>bin</code>, <code>oct</code>, <code>hex</code>.</li>
<li>Python работает с целыми числами любой длины, поэтому 9<sup>30</sup> посчитается точно.</li>
</ul>
--- code
def digits(n, base):
    """Цифры записи n в системе с основанием base, младшая — первая."""
    result = []
    while n:
        result.append(n % base)
        n //= base
    return result or [0]

print(digits(9**30 + 3**25 - 7, 3).count(2))     # 24
--- end
<p>Почему так много двоек? 9<sup>30</sup> = 3<sup>60</sup> — единица и 60 нулей. Вычитание 7 из 3<sup>25</sup> делает «заём» через младшие разряды, и нули превращаются в двойки. Поэтому такие задачи обычно можно решить и рассуждением, но программа надёжнее.</p>
<h3>Неизвестная цифра</h3>
<p>Пример: в выражении 3x7<sub>11</sub> + x25<sub>11</sub> буква x обозначает одну и ту же цифру системы с основанием 11. Найдите наименьшее x, при котором значение делится на 7, и запишите частное.</p>
--- code
alphabet = '0123456789A'                  # цифры системы с основанием 11
for x in range(1, 11):                    # x стоит первой цифрой во втором числе — не ноль
    d = alphabet[x]
    value = int(f'3{d}7', 11) + int(f'{d}25', 11)
    if value % 7 == 0:
        print(x, value // 7)              # 5 151
        break
--- end
<p>При x = 5: 357<sub>11</sub> = 425, 525<sub>11</sub> = 632, сумма 1057 = 7 · 151. Ответ — <strong>151</strong>.</p>
<h3>Частые ошибки</h3>
<ul>
<li>Перебирать x до 9, когда основание больше 10: цифры A, B, … тоже возможны.</li>
<li>Разрешать x = 0, когда x стоит первой цифрой числа.</li>
<li>Отвечать найденной цифрой, когда просят частное или значение.</li>
</ul>

=== quiz: Проверь себя: значение записи
? Чему равно число 2A<sub>16</sub> в десятичной системе?
+ 42
- 210
- 32
- 26
>> 2A₁₆ = 2 · 16 + 10 = 42. В Python то же самое даёт int('2A', 16).

=== answer: Мини-задача
<p>Сколько единиц содержится в двоичной записи значения выражения 8<sup>20</sup> + 4<sup>15</sup> − 16?</p>
= 27
>> 8²⁰ = 2⁶⁰, 4¹⁵ = 2³⁰, 16 = 2⁴. Число 2³⁰ − 2⁴ в двоичной записи — 26 единиц подряд (разряды с 4-го по 29-й), и ещё одна единица от 2⁶⁰. Всего 27. Проверка: bin(8**20 + 4**15 - 16).count('1').

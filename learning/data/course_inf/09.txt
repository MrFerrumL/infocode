=== theory: Как устроено задание
<p>К заданию прилагается файл электронной таблицы: в каждой строке несколько натуральных чисел. Нужно посчитать, сколько строк одновременно удовлетворяют условиям. Условия обычно про повторы и сравнение, например: «в строке ровно одно число повторяется дважды, остальные различны, и повторяющееся число не меньше среднего арифметического неповторяющихся».</p>
<h3>Способ 1 — в электронной таблице</h3>
<ol>
<li>Рядом со строкой посчитайте, сколько раз встречается каждое число: <code>=СЧЁТЕСЛИ($A1:$F1; A1)</code>, протяните на шесть столбцов и вниз.</li>
<li>Проверьте шаблон повторов: например, сумма этих счётчиков равна 8 только для набора 2, 2, 1, 1, 1, 1 (одно число дважды, четыре разных).</li>
<li>Посчитайте нужные величины: повторяющееся число — <code>=СУММЕСЛИ(G1:L1; 2; A1:F1)/2</code>, среднее неповторяющихся — <code>=СРЗНАЧЕСЛИ(G1:L1; 1; A1:F1)</code>.</li>
<li>Итоговый столбец с <code>=ЕСЛИ(И(…; …); 1; 0)</code> и сумма по нему — ответ.</li>
</ol>
<h3>Способ 2 — Python</h3>
<p>Сохраните лист как текстовый файл (CSV или TXT с разделителем) и обработайте строки программой. <code>Counter</code> сразу говорит, сколько раз встречается каждое число.</p>
--- code
from collections import Counter

def good(row):
    count = Counter(row)
    if sorted(count.values()) != [1, 1, 1, 1, 2]:      # одно число дважды, четыре разных
        return False
    repeated = [v for v, k in count.items() if k == 2][0]
    single = [v for v, k in count.items() if k == 1]
    return repeated >= sum(single) / len(single)

answer = 0
for line in open('9.txt'):
    row = [int(x) for x in line.replace(';', ' ').replace(',', ' ').split()]   # ; , табуляция
    answer += good(row)
print(answer)
--- end
<p>Условия меняются от варианта к варианту, а программа — нет: переписывается только функция проверки. Например, для условия «все числа в строке различны, и удвоенная сумма наибольшего и наименьшего больше суммы остальных»:</p>
--- code
def good(row):
    if len(set(row)) != len(row):                       # есть повторы
        return False
    big, small = max(row), min(row)
    return 2 * (big + small) > sum(row) - big - small
--- end

<p>Ответ для этой таблицы — <strong>1</strong>. Каждое условие отсекает свои строки: здесь видно и «не тот шаблон повторов», и «не прошло сравнение».</p>
<h3>Частые ошибки</h3>
<ul>
<li>Считать «повторяется» как «встречается не меньше двух раз», хотя нужно ровно дважды.</li>
<li>Делить на количество чисел в строке вместо количества неповторяющихся чисел.</li>
<li>Строгое и нестрогое сравнение: «не меньше» — это ≥.</li>
</ul>

=== quiz: Проверь себя: шаблон повторов
? В строке 6 чисел. Для каждого посчитали, сколько раз оно встречается в строке, и сложили эти счётчики. Получилось 8. Что это значит?
+ Одно число встречается дважды, остальные четыре — по одному разу
- Все шесть чисел различны
- Два числа встречаются по два раза
- Одно число встречается трижды
>> Если все различны — сумма 6 (шесть единиц). Одно число дважды: 2 + 2 + 1 + 1 + 1 + 1 = 8. Две пары: 2 · 4 + 1 + 1 = 10. Тройка: 3 · 3 + 1 + 1 + 1 = 12. Значит, 8 бывает только в первом случае.

=== theory: Как работает Черепаха
<p>Исполнитель Черепаха ходит по координатной плоскости и оставляет след. В начале она стоит в начале координат и смотрит вдоль оси Oy (вверх). Команды:</p>
<table>
<thead><tr><th>Команда</th><th>Что делает</th></tr></thead>
<tbody>
<tr><td>Вперёд n / Назад n</td><td>сдвиг на n единиц в направлении головы (или против него)</td></tr>
<tr><td>Направо m / Налево m</td><td>поворот на m градусов по часовой стрелке / против</td></tr>
<tr><td>Повтори k [ … ]</td><td>повторить команды в скобках k раз</td></tr>
<tr><td>Поднять хвост / Опустить хвост</td><td>перестать оставлять след / снова начать</td></tr>
</tbody>
</table>
<p>Обычно программа рисует один или два многоугольника, а спрашивают, сколько точек с целыми координатами лежит <strong>внутри</strong> фигуры (или внутри пересечения либо объединения двух фигур). Отдельно оговаривается, учитывать ли точки на линиях.</p>
<h3>Как решать</h3>
<ol>
<li>Пройдите программу на бумаге или программой и выпишите <strong>вершины</strong> фигур.</li>
<li>Для прямоугольников со сторонами вдоль осей считайте точки сразу: если x меняется от a до b, внутри (без границы) лежат b − a − 1 целых значений, с границей — b − a + 1.</li>
<li>Для наклонных сторон надёжнее программа: перебрать точки сетки и проверить, лежит ли точка внутри многоугольника.</li>
</ol>
<h3>Пример</h3>
<p>Программа: <code>Повтори 2 [Вперёд 9 Направо 90 Вперёд 6 Направо 90] Поднять хвост Вперёд 3 Направо 90 Вперёд 3 Налево 90 Опустить хвост Повтори 2 [Вперёд 9 Направо 90 Вперёд 6 Направо 90]</code>. Сколько точек с целыми координатами лежит внутри пересечения фигур, не считая точек на линиях?</p>
<ul>
<li>Первый прямоугольник: x от 0 до 6, y от 0 до 9.</li>
<li>Черепаха без следа переходит в точку (3; 3) и снова смотрит вверх. Второй прямоугольник: x от 3 до 9, y от 3 до 12.</li>
<li>Пересечение: x от 3 до 6, y от 3 до 9. Внутри: x = 4, 5 (2 значения), y = 4…8 (5 значений).</li>
</ul>
<p>Ответ: 2 · 5 = <strong>10</strong>.</p>
<h3>Программа для любых фигур</h3>
<p>Функция моделирует Черепаху и возвращает вершины каждой нарисованной фигуры, вторая — проверяет точку методом луча: луч вправо от точки пересекает границу нечётное число раз, только если точка внутри.</p>
--- code
from math import cos, sin, radians

def turtle(program):
    x = y = 0.0
    angle, down = 90.0, True              # смотрит вверх, хвост опущен
    figures, current = [], [(0.0, 0.0)]
    for cmd, *arg in program:
        if cmd == 'F':                    # Вперёд n (Назад n — это F с минусом)
            x += arg[0] * cos(radians(angle))
            y += arg[0] * sin(radians(angle))
            if down:
                current.append((round(x, 9), round(y, 9)))
        elif cmd == 'R':
            angle -= arg[0]
        elif cmd == 'L':
            angle += arg[0]
        elif cmd == 'U':
            down = False
            figures.append(current)
        elif cmd == 'D':
            down, current = True, [(round(x, 9), round(y, 9))]
    figures.append(current)
    return [f for f in figures if len(f) > 2]

def edges(poly):
    return zip(poly, poly[1:] + poly[:1])

def on_border(px, py, poly):
    """Точка лежит на одной из сторон."""
    return any(abs((x2 - x1) * (py - y1) - (y2 - y1) * (px - x1)) < 1e-9
               and min(x1, x2) - 1e-9 <= px <= max(x1, x2) + 1e-9
               and min(y1, y2) - 1e-9 <= py <= max(y1, y2) + 1e-9
               for (x1, y1), (x2, y2) in edges(poly))

def inside(px, py, poly):
    """Строго внутри: луч вправо пересекает стороны нечётное число раз."""
    if on_border(px, py, poly):
        return False
    result = False
    for (x1, y1), (x2, y2) in edges(poly):
        if (y1 > py) != (y2 > py) and px < x1 + (py - y1) * (x2 - x1) / (y2 - y1):
            result = not result
    return result

rect = [('F', 9), ('R', 90), ('F', 6), ('R', 90)] * 2
a, b = turtle(rect + [('U',), ('F', 3), ('R', 90), ('F', 3), ('L', 90), ('D',)] + rect)
print(sum(inside(x, y, a) and inside(x, y, b)
          for x in range(-50, 50) for y in range(-50, 50)))
--- end
<p>Программа печатает 10. Если точки на линиях нужно <em>учитывать</em>, считайте точки, для которых верно <code>inside(x, y, f) or on_border(x, y, f)</code>.</p>
<h3>Частые ошибки</h3>
<ul>
<li>Начать движение вправо: Черепаха в начале смотрит вверх.</li>
<li>Перепутать «внутри» и «внутри или на границе» — ответы различаются на всю длину контура.</li>
<li>Не заметить, что после «Поднять хвост» фигура уже замкнулась, и связать две фигуры в одну.</li>
</ul>

=== quiz: Проверь себя: начальное направление
? Черепаха стоит в начале координат и выполняет команды «Направо 90 Вперёд 5». Где она окажется?
+ В точке (5; 0)
- В точке (0; 5)
- В точке (−5; 0)
- В точке (0; −5)
>> Сначала голова направлена вверх, вдоль Oy. Поворот направо на 90° разворачивает её вдоль оси Ox в положительную сторону, поэтому «Вперёд 5» приводит в (5; 0).

=== answer: Мини-задача
<p>Черепаха выполняет программу <code>Повтори 2 [Вперёд 10 Направо 90 Вперёд 4 Направо 90]</code>.</p>
<p>Сколько точек с целыми координатами лежит внутри получившейся фигуры, <strong>включая</strong> точки на её границе?</p>
= 55
>> Фигура — прямоугольник: x от 0 до 4, y от 0 до 10. С границей x принимает 5 целых значений (0…4), y — 11 (0…10). Всего 5 · 11 = 55.

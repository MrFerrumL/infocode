=== theory: Как устроено задание
<p>Описан алгоритм: по числу N строится его двоичная (иногда троичная или другая) запись, к ней по правилу дописываются или заменяются цифры, а получившаяся запись переводится обратно в число R. Спрашивают, например, наименьшее N, при котором R больше заданного, или наименьшее R при таком условии.</p>
<h3>Главный приём — перебор</h3>
<p>Руками такие задания решать долго и легко ошибиться. Надёжнее записать алгоритм функцией и перебрать N.</p>
<ul>
<li><code>bin(n)[2:]</code> — двоичная запись числа без приставки <code>0b</code>.</li>
<li><code>int(s, 2)</code> — обратно из двоичной строки в число.</li>
<li><code>s.count('1')</code> — количество единиц, <code>s[-2:]</code> — две последние цифры, <code>s[::-1]</code> — строка задом наперёд.</li>
<li>Для других систем счисления пишут свою функцию перевода: остатки от деления на основание, собранные в обратном порядке.</li>
</ul>
<h3>Пример</h3>
<p>Алгоритм: строится двоичная запись N. Если N чётное, справа дописываются две последние цифры записи в обратном порядке; если нечётное — слева дописывается 1, а справа 0. Результат переводится в десятичную систему — это R. Найдём наименьшее R, большее 100.</p>
--- code
def build(n):
    s = bin(n)[2:]
    if n % 2 == 0:
        s = s + s[-2:][::-1]
    else:
        s = '1' + s + '0'
    return int(s, 2)

print(min(build(n) for n in range(1, 1000) if build(n) > 100))
--- end
<p>Программа печатает <strong>102</strong>. Проверим вручную одно значение: N = 6 = 110₂ — чётное, последние цифры «10» в обратном порядке дают «01», запись 11001₂ = 25.</p>
<h3>На что обратить внимание</h3>
<ul>
<li>Читайте, что ищут: наименьшее <strong>N</strong> или наименьшее <strong>R</strong>. Это разные числа, и функции <code>min</code> нужно отдавать разное.</li>
<li>Диапазон перебора берите с запасом: если ответ оказался на границе диапазона, увеличьте её.</li>
<li>Условия «чётное / нечётное» иногда относятся к числу N, а иногда — к количеству единиц в записи. Перепроверьте, к чему именно.</li>
</ul>

=== quiz: Проверь себя: двоичная запись в Python
? Как получить двоичную запись числа n в виде строки без приставки 0b?
+ bin(n)[2:]
- bin(n)
- str(n, 2)
- int(n, 2)
>> bin(n) возвращает строку вида '0b101', срез [2:] убирает приставку. int(s, 2) делает обратное — переводит двоичную строку в число.

=== answer: Мини-задача
<p>Алгоритм: строится двоичная запись N. Справа к ней дописывается остаток от деления количества единиц записи на 2. Затем справа дописывается 1, если первая и последняя цифры получившейся записи совпадают, и 0 — если различаются. Результат переводится в десятичную систему — это R.</p>
<p>Укажите наименьшее N, при котором R больше 60.</p>
= 16
>> Перебор функцией даёт N = 16: 10000₂ → одна единица, дописываем 1 → 100001 → первая и последняя цифры совпадают, дописываем 1 → 1000011₂ = 67. Для N = 15: 1111 → 11110 → 111100₂ = 60, это не больше 60.

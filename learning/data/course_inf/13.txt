=== theory: Как устроены IP-адрес и маска
<p><strong>IP-адрес</strong> (IPv4) — 32 бита, которые записывают четырьмя десятичными числами от 0 до 255 через точку: 192.168.10.37. Каждое число — один байт.</p>
<p><strong>Маска</strong> — тоже 32 бита: сначала идут только единицы, потом только нули. Единицы отмечают часть адреса, общую для всей сети, нули — номер узла в сети. Маску пишут как адрес (255.255.240.0) или числом единиц (/20).</p>
<ul>
<li><strong>Адрес сети</strong> = IP-адрес AND маска (побитовая конъюнкция): там, где в маске 0, в адресе сети стоят нули.</li>
<li>Если в маске k нулей, в сети 2<sup>k</sup> адресов. Первый из них — адрес сети, последний — широковещательный; узлам обычно можно назначить 2<sup>k</sup> − 2 адреса. Внимательно читайте, о каких адресах спрашивают.</li>
<li>Байт маски может быть только одним из чисел: 0, 128, 192, 224, 240, 248, 252, 254, 255.</li>
</ul>
<h3>Пример</h3>
<p>IP-адрес 172.16.75.130, маска 255.255.240.0. Первые два байта маски — 255, они переносят 172.16 без изменений. Третий байт: 75 = 0100 1011, 240 = 1111 0000, AND = 0100 0000 = 64. Четвёртый байт маски 0 → в адресе сети 0. Адрес сети: <strong>172.16.64.0</strong>. В маске 4 + 8 = 12 нулей → 2<sup>12</sup> = <strong>4096</strong> адресов.</p>
<h3>Обратная задача</h3>
<p>Известны IP-адрес узла 172.16.75.130 и адрес сети 172.16.64.0. Какие маски возможны? Перебираем число единиц в маске и оставляем те, при которых получается нужный адрес сети.</p>
--- code
from ipaddress import ip_address, ip_network

node, network = '172.16.75.130', ip_address('172.16.64.0')
masks = [m for m in range(33)
         if ip_network(f'{node}/{m}', strict=False).network_address == network]
print(masks)                       # [18, 19, 20]
--- end
<p>Подходят маски с 18, 19 или 20 единицами. Значит, наибольшее число единиц — 20, наименьшее — 18, а третий байт маски может быть 192, 224 или 240. Модуль <code>ipaddress</code> есть в стандартной библиотеке Python: <code>ip_network(…).num_addresses</code> даёт число адресов, а перебор <code>for a in net</code> — все адреса сети, если нужно посчитать адреса с особым свойством.</p>
<h3>Частые ошибки</h3>
<ul>
<li>Применять маску к десятичным числам «на глаз»: AND делается по битам.</li>
<li>Путать «адресов в сети» и «адресов, которые можно назначить узлам» (минус два).</li>
<li>Забывать, что маска — это единицы <em>подряд</em>: 255.255.250.0 маской быть не может.</li>
</ul>

=== quiz: Проверь себя: какой байт маски возможен
? Какое число может быть байтом маски?
+ 248
- 250
- 127
- 200
>> Байт маски — несколько единиц подряд, затем нули. 248 = 1111 1000 подходит. 250 = 1111 1010, 127 = 0111 1111 и 200 = 1100 1000 содержат «дыры» и маской быть не могут.

=== answer: Мини-задача
<p>Узел имеет IP-адрес 10.8.200.37, маска сети 255.255.248.0.</p>
<p>Сколько всего адресов в этой сети (включая адрес сети и широковещательный)?</p>
= 2048
>> 248 = 1111 1000 — в третьем байте 3 нуля, в четвёртом байте маски 8 нулей. Всего 11 нулей, значит адресов 2¹¹ = 2048.

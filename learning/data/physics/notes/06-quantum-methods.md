# Квантовая физика и методология (задания 16–20)

## Фотоэффект

- Энергия фотона E = hν = hc/λ, h = 6,6·10⁻³⁴ Дж·с.
- Уравнение Эйнштейна: hν = Aвых + mv²/2; задерживающее напряжение eUз = mv²/2.
- Красная граница: νmin = Aвых/h. Ниже неё фотоэффекта нет при любой интенсивности.
- Интенсивность (число фотонов) влияет на число фотоэлектронов, но не на их энергию.

## Атом

- При переходе между уровнями испускается (или поглощается) фотон hν = Eₘ − Eₙ.
- Чем больше разность уровней, тем больше частота и меньше длина волны фотона.

## Ядро

- Ядро содержит Z протонов и N = A − Z нейтронов; A — массовое число.
- α-распад: A уменьшается на 4, Z — на 2. β⁻-распад: A не меняется, Z увеличивается на 1.
- В ядерных реакциях сохраняются суммарное массовое и зарядовое числа.
- Закон радиоактивного распада: N = N₀ · 2^(−t/T); за время, равное периоду полураспада, распадается половина ядер.

## Задание 19: показания приборов

- Цена деления = разность соседних подписанных значений / число делений между ними.
- Если сказано, что погрешность равна цене деления (или половине цены), запишите результат в виде «значение ± погрешность» — с одинаковым числом знаков после запятой.
- Метод рядов: толщину одной монеты (бусины) находят как общую длину ряда, делённую на число предметов; погрешность делится так же.

## Задание 20: выбор опытов

Для проверки зависимости от одной величины выберите опыты, в которых **меняется только она**, а все остальные условия одинаковые.

# Электродинамика (задания 11–15, 21, 23)

## Электростатика

- Закон Кулона: F = k|q₁q₂|/r², k = 9·10⁹ Н·м²/Кл².
- Напряжённость поля точечного заряда E = k|q|/r²; принцип суперпозиции — векторное сложение.
- Работа поля A = qU; потенциал φ = kq/r.
- Ёмкость конденсатора C = q/U; плоского C = εε₀S/d.
- Энергия конденсатора W = CU²/2 = q²/(2C) = qU/2.
- Если конденсатор **отключён** от источника, сохраняется заряд; если **подключён** — напряжение.

## Постоянный ток

- Сила тока I = q/t; закон Ома для участка I = U/R; R = ρl/S.
- Последовательно: R = R₁ + R₂, ток одинаковый. Параллельно: 1/R = 1/R₁ + 1/R₂, напряжение одинаковое.
- Закон Ома для полной цепи: I = ℰ/(R + r); напряжение на внешней цепи U = ℰ − Ir.
- Мощность P = UI = I²R = U²/R; закон Джоуля — Ленца Q = I²Rt.

## Магнитное поле

- Сила Ампера Fₐ = BIl sin α (правило левой руки).
- Сила Лоренца F = |q|vB sin α; заряд в поле движется по окружности R = mv/(|q|B), период T = 2πm/(|q|B) не зависит от скорости.
- Сила Лоренца перпендикулярна скорости и работы не совершает.

## Электромагнитная индукция

- Магнитный поток Φ = BS cos α.
- Закон Фарадея: |ℰ| = |ΔΦ|/Δt; в движущемся проводнике ℰ = Bvl.
- Правило Ленца: индукционный ток препятствует изменению потока.
- Самоиндукция: Φ = LI, ℰ = −LΔI/Δt; энергия катушки W = LI²/2.

## Колебательный контур

- Формула Томсона T = 2π√(LC).
- Сохранение энергии: q²max/(2C) = LI²max/2.
- Длина электромагнитной волны λ = cT.

Найдите величину, которая не меняется (q, U, ℰ, B…), выразите через неё искомые величины и проверьте, как они изменятся.

# Оптика (задания 13, 15, 25)

## Отражение

- Угол отражения равен углу падения; углы отсчитываются от нормали к поверхности.
- Изображение в плоском зеркале мнимое, равное предмету и симметричное ему относительно зеркала.

## Преломление

- Закон Снеллиуса: n₁ sin α = n₂ sin β; показатель преломления n = c/v.
- При переходе в другую среду **частота света не меняется**, меняются скорость и длина волны: λ = λ₀/n.
- Полное внутреннее отражение (из более плотной среды): sin α₀ = n₂/n₁ (в воздух — 1/n).

## Линзы

- Формула тонкой линзы: 1/d + 1/f = 1/F (для мнимого изображения f < 0, для рассеивающей линзы F < 0).
- Оптическая сила D = 1/F (дптр).
- Увеличение Γ = f/d = H/h.
- Собирающая линза: d > 2F — уменьшенное действительное; F < d < 2F — увеличенное действительное; d < F — мнимое увеличенное.

## Как строить изображение

Луч, идущий параллельно главной оптической оси, после собирающей линзы проходит через фокус; луч через оптический центр не преломляется. Точка пересечения — изображение.

Нарисуйте ход лучей, обозначьте все расстояния, запишите формулу линзы (или закон Снеллиуса) и геометрические соотношения из рисунка.

# Молекулярная физика и термодинамика (задания 7–10, 21, 24)

## Основы МКТ

- Количество вещества ν = m/M = N/Nₐ, Nₐ = 6·10²³ моль⁻¹.
- Концентрация n = N/V.
- Основное уравнение МКТ: p = (1/3)m₀nv² = (2/3)nE, где E — средняя кинетическая энергия поступательного движения молекулы.
- Связь с температурой: E = (3/2)kT, k = 1,38·10⁻²³ Дж/К; p = nkT.
- T (К) = t (°C) + 273.

## Уравнение состояния идеального газа

- Менделеева — Клапейрона: pV = νRT, R = 8,31 Дж/(моль·К).
- Изотермический процесс (T = const): pV = const.
- Изобарный (p = const): V/T = const.
- Изохорный (V = const): p/T = const.

## Термодинамика

- Внутренняя энергия одноатомного идеального газа: U = (3/2)νRT.
- Работа газа при p = const: A = pΔV; в общем случае — площадь под графиком на pV-диаграмме.
- Первый закон: Q = ΔU + A (A — работа газа).
- Адиабатный процесс: Q = 0, ΔU = −A.
- Количество теплоты: нагревание Q = cmΔt; плавление Q = λm; парообразование Q = Lm; сгорание Q = qm.
- Уравнение теплового баланса: сумма отданной и полученной теплоты равна нулю.
- КПД теплового двигателя: η = (Q₁ − Q₂)/Q₁ = A/Q₁; цикл Карно: ηmax = 1 − Tх/Tн.

## Влажность

- Относительная влажность φ = p/pнас · 100 %.
- Давление насыщенного пара зависит только от температуры (не от объёма): при сжатии над жидкостью пар конденсируется, давление не меняется.

## Как решать задания 9 и 10

2. Запишите закон процесса и первый закон термодинамики.
3. Для каждой величины проверьте знак её изменения по формуле.

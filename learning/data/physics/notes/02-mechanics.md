# Механика: формулы и приёмы (задания 1–6, 22, 26)

## Кинематика

- Равномерное движение: x = x₀ + vₓt.
- Равноускоренное: vₓ = v₀ₓ + aₓt; x = x₀ + v₀ₓt + aₓt²/2; vₓ² − v₀ₓ² = 2aₓsₓ.
- **Путь по графику vₓ(t)** — площадь под графиком (части под осью берутся по модулю).
- **Проекция ускорения** — наклон графика vₓ(t): aₓ = Δvₓ/Δt; знак важен.
- Свободное падение: a = g = 10 м/с², направлено вниз.
- Движение по окружности: v = 2πR/T, центростремительное ускорение a = v²/R = ω²R.
- Бросок горизонтально: x = v₀t, y = h − gt²/2; время падения t = √(2h/g).

## Динамика

- Второй закон Ньютона: ma⃗ = ΣF⃗.
- Третий закон: F⃗₁₂ = −F⃗₂₁.
- Закон Гука: F = kx (x — удлинение).
- Сила трения скольжения: F = μN; трение покоя ≤ μN.
- Закон всемирного тяготения: F = Gm₁m₂/r²; g на высоте h: g = GM/(R + h)².
- Вес тела в лифте, движущемся с ускорением вверх: P = m(g + a).
- Первая космическая скорость: v = √(gR) = √(GM/R).

## Законы сохранения

- Импульс p⃗ = mv⃗; импульс силы FΔt = Δp.
- Закон сохранения импульса — для замкнутой системы (или если внешние силы малы по сравнению с внутренними, например при ударе).
- Работа силы: A = Fs cos α; мощность N = A/t = Fv.
- Кинетическая энергия Eк = mv²/2; потенциальная Eп = mgh; энергия пружины Eп = kx²/2.
- Закон сохранения механической энергии — если работают только потенциальные силы (тяжести, упругости); при трении ΔE = Aтр.
- Неупругий удар: импульс сохраняется, механическая энергия — нет (выделяется теплота).

## Статика и гидростатика

- Момент силы M = Fl (l — плечо); правило моментов: ΣM = 0.
- Давление p = F/S; давление жидкости p = ρgh.
- Сила Архимеда Fₐ = ρж g Vпогр. Условие плавания: Fₐ = mg.

## Колебания и волны

- Пружинный маятник: T = 2π√(m/k); математический: T = 2π√(l/g).
- Частота ν = 1/T; циклическая ω = 2πν.
- Длина волны λ = vT = v/ν.
- При колебаниях энергия переходит из кинетической в потенциальную: kA²/2 = mv²max/2.

## Задание 26: обоснование

Перед решением укажите: тело — материальная точка; система отсчёта инерциальная; нить нерастяжима и невесома; трения нет (или оно учтено); для закона сохранения импульса — система замкнута или удар кратковременный; для закона сохранения энергии — работают только потенциальные силы.

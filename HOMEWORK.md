# Домашние задания: повторные попытки и решения ученика

## Преподавателю

1. Откройте **Домашние задания → Назначить ДЗ**. Выберите подборку задач, готовый вариант или ручную проверку; назначьте учеников и срок.
2. Для ДЗ из задач настройте Python-код: по желанию или обязательный вместе с ответом. Ученик может приложить код к любой задаче ДЗ, даже если в банке у неё стоит «Без Python-кода». Настройки банка и снимок уже выданного варианта не изменяются.
3. **Лимит попыток: 0** означает отсутствие ограничения. Это значение предлагается для новых ДЗ; можно выбрать 1–100. Лимит учитывает начатые попытки, включая завершённые по таймеру. Текущую попытку можно продолжать, пока её время не истекло.
4. Откройте карточку назначенного ДЗ: в **Получатели и все попытки** видны ученики, зачёт, число попыток, лучший и последний результат. Раскройте **Все попытки** и откройте результат нужной сдачи. В нём отдельно показаны ответ, код и комментарий к каждой задаче. Время указано по Москве.
5. Для изменения лимита уже назначенного ДЗ раскройте **Настроить повторные попытки**. Изменение не удаляет прошлые решения и зачёт. При ограниченном числе попыток можно выдать **+1 попытку** отдельному ученику.

Каждая отправка варианта создаёт уведомление преподавателю. Результаты доступны ученику, автору назначения и администратору. Другой преподаватель того же ученика не получает доступ к частному назначению. Автор сохраняет доступ к истории своего назначения после открепления ученика.

## Ученику

1. Откройте **Домашние задания**, выберите работу и нажмите **Начать ДЗ**.
2. Для каждой задачи введите ответ; при желании добавьте **Решение на Python** и **Комментарий к задаче**. В поле кода сохраняются отступы; Tab вставляет четыре пробела. Кнопка **Вставить из .py** читает файл UTF-8 в поле.
3. Нажмите **Сохранить ответы, код и комментарии**, если хотите продолжить позднее. Простого ввода в поля недостаточно для сохранения. Кнопка **Продолжить попытку** возвращает в тот же бланк до окончания времени.
4. Нажмите **Сдать и получить результат**. В истории останутся ответы, код, комментарии, время и результат этой попытки.
5. Нажмите **Начать заново** в карточке ДЗ или на странице результата. Откроется отдельная попытка с пустыми полями. Старые решения не перезаписываются, а полученный зачёт не теряется при последующих ошибках.

Python-код — до 20 000 символов на задачу, комментарий — до 3000. Код хранится для преподавателя и не запускается на сервере. Автоматический балл вычисляется по ответу; для задач с обязательным кодом нужно приложить программу. Оценка правильности самой программы автоматически не выполняется.

## Ручная проверка

В ДЗ с ручной проверкой можно отправить текст/комментарий, Python-код, фото и файл. Каждая отправка — отдельная попытка. Можно отправить новую, пока предыдущая находится на проверке. В карточке сохраняются все версии и обратная связь преподавателя. Преподаватель открывает каждую попытку отдельно и зачтёт или вернёт её на доработку. Новая неудачная сдача и возврат другой версии не снимают уже полученный зачёт.

## Сроки и другие назначения

- Срок сдачи, дата открытия и закрытие преподавателем действуют при каждом повторе. Если разрешена поздняя сдача, можно повторять после срока.
- При окончании времени сохраняется и оценивается последняя сохранённая версия; введённые после окончания времени поля не принимаются.
- Обязательные КР сохраняют установленный лимит и блокировку после зачёта. Значение 0 для обязательной КР не допускается.
- ДЗ в виде урока курса проверяет существующий прогресс урока. Повторные попытки целой подборки относятся к ДЗ из задач и ручным отправкам; прогресс курса не обнуляется.

## Установка обновления

Локально из папки проекта:

```powershell
python start_local.py
```

Запуск применит миграцию `0013` и обновит оформление. Если старый процесс сайта работает, сначала остановите его Ctrl+C, затем запустите заново. Обновите страницу Ctrl+F5.

На VPS используйте раздел «Обновить приложение» в [DEPLOYMENT.md](DEPLOYMENT.md): свежая резервная копия, обновление исходников, сборка, миграция, запуск сервисов. Не заменяйте серверную базу локальной базой.

При первом применении `0013` ранее выданные ДЗ из задач и с ручной проверкой с лимитом **1** становятся без ограничения. Лимиты 2–100, обязательные КР и назначения уроков сохраняются. Все ученики, задания, предыдущие ответы и зачёты сохраняются.

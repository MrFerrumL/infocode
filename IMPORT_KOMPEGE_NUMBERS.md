# Полные разделы КОМПЕГЭ №2 и №3

Снимок публичного банка от 17.10.2026, перенос разрешён пользователем:

| Раздел | Заданий | Исходных файлов |
|---|---:|---:|
| №2 | 230 | 0 |
| №3 | 223 | 231 |

Тексты не переписываются моделью и не распознаются OCR. Оригинальный HTML безопасно отображается локально с исходными формулами, таблицами и изображениями; затем нативный браузер снимает всё условие при масштабе 2× (ширина 1920 пикселей). Для каждого снимка проверяются загрузка иллюстраций, отсутствие ошибок формул и горизонтального переполнения. Снимки используют существующий просмотрщик с увеличением и поддержкой светлой и тёмной темы. Ответы проверяются на странице каталога.

231 файл скачан с исходными именами: 117 XLSX, 76 XLS и 38 ODS. Проверены контрольные суммы, структура ZIP для XLSX/ODS и сигнатура OLE для XLS. Условие хранится в изображении; правильный ответ сохраняется в БД и доступен ученику после собственной попытки.

## Повторяемый импорт

1. `python deploy/prepare_kompege_numbers.py <папка> --numbers 2 3` — сохранить снимки публичных API и оригинальные файлы, подготовить HTML.
2. Нативным браузером снять страницы из `jobs.json` в `captures/` и сохранить `capture-report.json`; запуск стороннего браузерного движка вместо этого этапа не предусмотрен.
3. `python deploy/package_kompege_numbers.py <папка> ../kompege-numbers23.zip` — собрать проверенный пакет.
4. `python manage.py import_kompege_numbers ../kompege-numbers23.zip --numbers 2 3 --dry-run` — проверка без записи.
5. `python manage.py import_kompege_numbers ../kompege-numbers23.zip --numbers 2 3 --publish` — добавить недостающие задачи.

Пакет содержит точный перечень разделов, количества и SHA-256 исходных API. Команда отказывает при несовпадении с `--numbers`, неполном разделе, повторном идентификаторе, неверной сумме файла или низком разрешении условия. Для повторного запуска используется пара «номер + ID источника». Существующие задачи, в том числе архивные, их правки, файлы и ученические попытки не заменяются.

Для VPS после сборки архива исходников: `python deploy/install_kompege_pilot.py --categories ../kompege-numbers23.zip --numbers 2 3`. Установщик сохраняет рабочую БД, медиа и исходники до обновления, импортирует только выбранные разделы и проверяет файлы и состояние сайта. `.env.production` не копируется в архивы исходников и не меняется.

Проверки кода: 318 тестов Django прошли, в том числе целостность файлов, повторный импорт, сохранение правок/архива/попыток, откат после ошибки и ограничение выбранных разделов. Отдельная база используется для локальной проверки интерфейса.

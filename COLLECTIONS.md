# Подборки

Раздел **Подборки** в меню. Одна строка на номер ЕГЭ:

- **Подборки Инфокода** — «знакомство», «на подумать», «повторение» по 10 задач из каталога (банки КЕГЭ и К. Полякова). Задачи решаются прямо на странице подборки, как в каталоге: проверка ответа, история, разбор, группы 19–21. Рядом с подборкой виден прогресс ученика (решено X из 10).
  - «повторение» — задачи реальных ЕГЭ, демоверсий и ЕГКР (по пометке источника);
  - «знакомство» — простые задачи, при нехватке — первые задачи К. Полякова;
  - «на подумать» — сложные задачи;
  - задачи в подборках номера не повторяются.
- **Яндекс Учебник** — 73 готовые подборки методистов Учебника. Это только ссылки: подборка открывается на education.yandex.ru в новой вкладке. Задачи Яндекса на сайт не копируются — разрешения на это нет.

## Обновление

Подборки Инфокода пересобираются из текущего каталога, ссылки Яндекса — из `learning/data/yandex_collections.json` (название и идентификатор подборки):

```
python manage.py sync_collections            # по 10 задач
python manage.py sync_collections --size 15  # другой размер
```

Повторный запуск безопасен: прогресс учеников хранится по задачам и не теряется. Отдельную подборку можно поправить вручную: Ещё → Полная админка → Подборки (порядок задач, снятие с публикации).

## Перенос подборок Яндекс Учебника

Учитель сохраняет задачи подборок сам (по его словам, у него есть разрешение Яндекса; задачи только для его учеников — раздел виден после входа). Одна папка на подборку, названная как на Яндексе:

```
№ 1 — знакомство/
    01.png          условие задачи 1 (ещё картинки: 01-2.png, 01-3.png)
    01-data.xlsx    файл к задаче 1 (любое имя, начинающееся с «01-»)
    ответы.txt      по строке на задачу: «1: 15» (несколько чисел — через пробел)
```

```
python manage.py import_yandex_collections <папка или zip> --dry-run   # только проверка
python manage.py import_yandex_collections <папка или zip>
```

Задачи попадают в каталог (сайт «Яндекс»), подборка решается на сайте. Ещё не перенесённые подборки остаются ссылками. Повторная загрузка обновляет те же задачи, ответы учеников сохраняются.

# Сезонное оформление

`SITE_SEASON=auto` (по умолчанию) включает украшения по календарю (`learning/seasons.py`):

- **Хеллоуин** (15 октября — 2 ноября): оранжево-фиолетовый отсвет, тыква у логотипа, паутина в углу, падающие листья и летучие мыши;
- **Зима** (3–30 ноября, 15 января — февраль): иней, снежинка у логотипа, снегопад;
- **Новый год** (1 декабря — 14 января): иней с красным и золотым, ёлка у логотипа, мигающая гирлянда сверху, снег.

Кнопка ❄ / 🎃 / 🎄 вверху выключает движение (запоминается в браузере). На экзаменационной станции и при «уменьшении движения» анимации нет. Принудительно: `SITE_SEASON=halloween|winter|newyear`, выключить: `SITE_SEASON=none` в `.env.production`.

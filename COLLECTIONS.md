# Подборки

Раздел **Подборки** в меню. Одна строка на номер ЕГЭ, подборки названы так же, как готовые подборки Яндекс Учебника (73 названия из `learning/data/yandex_collections.json`; номерам, которых там нет, даются «знакомство», «на подумать», «повторение»).

Задачи в подборки берутся из каталога сайта — банки КЕГЭ и К. Полякова. Задачи Яндекса на сайт не копируются (разрешения нет), ссылок на Яндекс в разделе нет.

- тема подборки («двоичная система счисления», «звуки», «с двумя кучами»…) — по тегам из `learning/data/task_topics.json` (`deploy/build_task_topics.py`, правила в `learning/collection_topics.py`);
- уровень: «знакомство» — простые, «на подумать» / «решаем кодом» — сложные, «повторение» / «уровень ЕГЭ» — реальные ЕГЭ, демоверсии и ЕГКР;
- задачи внутри одного номера не повторяются; решаются прямо на странице подборки, у ученика виден прогресс.

## Обновление

```
python manage.py sync_collections            # по 10 задач
python manage.py sync_collections --size 15  # другой размер
```

Повторный запуск безопасен: прогресс учеников хранится по задачам. Старые ссылки на Яндекс удаляются при запуске.

# Зимнее оформление

`SITE_SEASON=winter` (по умолчанию): лёгкий иней на фоне, снежинка у логотипа и снегопад с кнопкой ❄ (выключается, запоминается в браузере; на экзаменационной станции и при «уменьшении движения» снега нет). Выключить: `SITE_SEASON=` в `.env.production`.

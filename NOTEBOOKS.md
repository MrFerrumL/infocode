# Конспекты с ячейками

## Создать конспект

1. В кабинете преподавателя откройте **Конспекты → Новый конспект**.
2. Введите название. В «Описание и доступ» можно указать описание и группу. Если группа не выбрана, опубликованный конспект доступен всем зарегистрированным ученикам.
3. Добавляйте ячейки кнопками **Текст, Код, Фото, Видео, Файл, Линия**. Порядок свободный, до 40 ячеек в одном документе.
4. В текстовой ячейке выделите текст и выберите жирный, курсив, подчёркивание, заголовок, список, цитату или ссылку. Изображение можно вставить из буфера: ячейка будет разделена на текст до картинки, картинку и текст после неё. Вставка фото/видео в месте курсора также доступна на панели форматирования.
5. В ячейке Python пишите код с сохранением отступов либо нажмите **«Вставить из .py»**. Tab добавляет четыре пробела, Enter сохраняет отступ; Shift+Tab позволяет выйти из поля. В одной ячейке — до 100 000 символов.
6. Для файлов можно выбрать загрузку с компьютера или материал из медиатеки. Изображения: PNG/JPG/JPEG/WebP, до 20 МБ. Видео: MP4/WebM, до 500 МБ. Файлы: TXT, CSV, XLSX, PDF, ZIP, DOCX, PY, до 20 МБ.
7. Переставляйте ячейки стрелками или перетаскивайте за ручку ⠿. «Копия» дублирует ячейку, × удаляет после сохранения. Удалённую ячейку можно вернуть до сохранения.
8. **Предпросмотр** показывает ещё не сохранённый документ. **Сохранить конспект** сохраняет его; **Сохранить и посмотреть** открывает страницу чтения.
9. Включите **«Опубликовать для учеников»**, когда материал готов. Пустой документ можно сохранить черновиком, но нельзя опубликовать.

Черновик автоматически сохраняет текст и настройки приватно на сервере. После перезагрузки появится кнопка восстановления. Новые локальные фото и файлы необходимо выбрать заново: они отправляются только при полном сохранении. Если два окна редактируют один конспект, устаревшая форма не перезапишет последнюю сохранённую версию.

## Добавить в курс

1. Создайте и опубликуйте конспект в разделе «Конспекты».
2. Откройте **Курсы → курс → урок → слайд**.
3. Нажмите **«Добавить → Конспект»** и выберите документ. Обычный преподаватель выбирает свои документы; администратор — любые.
4. В этот же слайд можно добавить пояснения, видео, фото и задание. Выберите тип **«Материал + тест»** или **«Материал + практика»**, если нужен ответ ученика.
5. Для отдельного слайда с конспектом выберите тип **«Конспект»**. Он также доступен в плане слайдов нового урока.
6. Сохраните и опубликуйте слайд. Для доступа ученика должны быть опубликованы курс, урок, слайд и конспект. Ученик должен записаться на курс; при последовательном прохождении требуется завершить предыдущие слайды.

Конспект подключается как общий материал. Правки в нём появятся во всех связанных слайдах. После изменения содержания прежние ответы останутся в истории, а прохождение связанных слайдов будет относиться к новой версии материала. В редакторе конспекта есть ссылки на ваши уроки, где он используется.

Группа конспекта определяет его доступность в отдельной библиотеке. **Внутри курса доступ определяется курсом**: записанный ученик сможет открыть подключённый конспект и его вложения, даже если группа отдельной библиотеки другая. Ссылка с параметром слайда не обходит запись, ограничения группы курса или последовательность прохождения.

Если снять публикацию конспекта или переместить его в корзину, связанные слайды автоматически переходят в черновики. После публикации/восстановления конспекта проверьте и опубликуйте эти слайды заново.

## Как видит ученик

В боковом меню есть **«Конспекты»** с поиском опубликованных материалов. Документ отображается ячейками, с содержанием и подсветкой Python-кода. Ученик может копировать код, смотреть иллюстрации и видео, скачивать материалы. «Печать / PDF» открывает системное окно печати, где можно сохранить документ как PDF.

Код используется для редактирования и отображения. Ячейки не запускаются в браузере или на сервере; это выбранный режим для этой версии. Формат хранения — база платформы, обмен `.ipynb` с Colab в этом обновлении не добавлен.

## Удалить и восстановить

В редакторе откройте **«Переместить в корзину»**, проверьте название и количество связанных слайдов, затем подтвердите. Ячейки и физические файлы сохранятся. Откройте **Ещё → Корзина → Конспекты → Восстановить**. Восстановленный конспект является черновиком: проверьте его, опубликуйте и затем опубликуйте нужные слайды.

Обычный преподаватель редактирует и удаляет только свои конспекты. Администратор может работать с конспектами всех преподавателей. Удаление через стандартную Django-админку также перемещает документ в корзину.

## Обновить локальный проект

Из папки проекта:

```powershell
python start_local.py
```

Если приложение уже работает, сначала остановите его Ctrl+C. Запуск применит миграцию `0011` и соберёт оформление. Обновите страницу Ctrl+F5.

При запуске без `start_local.py`:

```powershell
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py collectstatic --noinput
.\.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000
```

На сервере используйте порядок обновления и резервного копирования из [DEPLOYMENT.md](DEPLOYMENT.md). Пользователи, курсы и существующие материалы не заменяются миграцией.

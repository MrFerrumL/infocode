# Сборник К. Полякова (№ 1–25)

Задачи для тренировки со страницы https://kpolyakov.spb.ru/school/ege.htm. Номер 17 загружен раньше (`deploy/prepare_polyakov_doc.py`), остальные — `deploy/prepare_polyakov_bank.py`.

- Каждая задача вырезается из DOC (переведённого LibreOffice в PDF) картинкой шириной 1920 px — так, как она набрана у Полякова; задача на стыке страниц склеивается.
- Ответы — из `answers.xls`, видеоразборы (ссылки в ответах) — в разборе задачи.
- Файлы к задачам — из архивов `3data.zip`, `9data.zip`, `18data.zip`, `22data.zip`, `23data.zip`, `24data.zip` (вложенные архивы тоже открываются).
- Нумерация как у Полякова: «задача 7.15», дополнительные документы номера 7 — «7-2.15» (звук) и «7-v.3» (скорость передачи), игры — «19-21.4».
- Номера заданий — по ЕГЭ-2027, как у Полякова и КЕГЭ: 10 — IP-адреса и маски, 13 — подсчёт программ («динамическое программирование»), 23 — алгоритмы на графах; поиска в текстовом документе в экзамене больше нет. Документ, у которого на первой странице стоит другой номер, сборщик не принимает. Заголовки разделов сайта переводятся на эту нумерацию командой `manage.py retitle_topics_2027` (есть `--dry-run` и `--reverse`).
- 19–21: у Полякова вопросы 19, 20, 21 написаны один раз на раздел («Вопросы 19-21 к следующим задачам»). Каждая задача получает своё условие и вопросы своего раздела; в каталоге это одна карточка с тремя ответами.
- Задачи, которые уже есть в банке КЕГЭ, пропускаются: совпадает ответ, текст и числа в условии.

```
soffice --headless --convert-to pdf --outdir conv src/*.doc
python deploy/prepare_polyakov_bank.py bank-a.zip conv src/answers.xls WORK 1 2 3 4 5 6
python deploy/prepare_polyakov_bank.py bank-g.zip conv src/answers.xls WORK 1921
python deploy/install_kompege_pilot.py --polyakov bank-a.zip bank-b.zip …   # резервная копия, затем импорт
```

Повторный импорт безопасен: уже загруженные задачи пропускаются.

# Кнопка «Похожие»

Под каждой задачей каталога и подборок — кнопка «≈ Похожие». Она показывает ниже до 5 задач того же номера с похожим условием; их можно решать прямо там. Сначала идут задачи, которые ученик ещё не решил.

Похожесть считает нейросеть (многоязычная модель текстовых эмбеддингов `intfloat/multilingual-e5-small`) по текстам условий КЕГЭ и К. Полякова — заранее, на компьютере разработчика:

```
python deploy/build_similar_tasks.py WORK learning/data/similar_tasks.json.gz
python manage.py sync_similar_tasks      # установщик запускает сам после импорта
```

Для задач без текста (свои, Яндекс Учебник) подбираются задачи того же номера и уровня.

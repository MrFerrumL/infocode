# Публичные страницы

Без входа доступны:

- `/` — описание платформы и кнопки «Войти» / «Регистрация ученика». Вошедший пользователь по этому адресу видит свой кабинет, как раньше.
- `/contacts/` — контакты, порядок получения доступа и как используются данные учеников.
- `/robots.txt` — разрешает индексировать только эти страницы, вход и регистрацию; закрытые разделы исключены.

Все остальные разделы по-прежнему требуют входа.

Зачем: раньше любой адрес сайта сразу вёл на форму пароля. У нового домена это частая причина пометки Google Safe Browsing «Опасный сайт» (подозрение на фишинг).

## Контакты

Контакты задаются переменными в `.env.production` на сервере. Пустые значения не показываются: без них страница советует ученикам обращаться к преподавателю.

```
SITE_OWNER_NAME=Имя преподавателя
SITE_CONTACT_EMAIL=почта@example.ru
SITE_CONTACT_TELEGRAM=ник_в_telegram
```

После изменения: `docker compose --env-file .env.production -f compose.production.yaml up -d`.

## Снятие предупреждения Google

1. Search Console → добавить ресурс «Домен» `infocode1.ru`, подтвердить записью TXT в DNS.
2. «Безопасность и меры, принятые вручную» → «Проблемы безопасности»: посмотреть причину и примеры адресов.
3. Нажать «Запросить проверку» и описать изменения: появилась публичная страница с описанием и контактами, форма входа отправляет данные только на этот домен.
